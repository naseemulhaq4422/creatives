## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (70% solid dark surfaces, 20% subtle glass, 10% purple/cyan accents)
- **Icons**: Lucide React
- **Email Backend**: Next.js API Routes + Nodemailer / Web3Forms fallback
- **Analytics & SEO**: Schema.org JSON-LD (`Organization`, `Service`, `Course`, `FAQPage`)
